# Support

Use GitHub Discussions for setup questions, ideas, and workflow feedback. Open a GitHub issue for reproducible bugs and include:

- the server version and operating system;
- selected transport and tool profile;
- the failing command or tool name;
- sanitized logs and the output of `polymarket-mcp-rs doctor --online` when relevant.

Remove private keys, authenticated API credentials, wallet secrets, tunnel credentials, and unrelated personal data before posting. Security vulnerabilities belong in GitHub private vulnerability reporting as described in [SECURITY.md](SECURITY.md), not a public issue.

The project is community-supported and provides no uptime, response-time, trading, or financial guarantee.
